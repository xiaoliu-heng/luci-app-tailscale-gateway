# 验证范围

`0.2.3-r1` 增加独立的内存保护服务和 LuCI 页面，并在同一台 OpenWrt SNAPSHOT 路由器完成 APK 升级与实机验收。34 项内存后台断言验证进程识别、范围/类型校验、独立配置版本、失败恢复、开关和无关配置保留；6 项真实 BusyBox 循环断言使用隔离 `/proc` 与 CLI 验证在线回收、锁、冷却、两次上限和 PID 重用；11 项页面断言验证草稿保留、权限、异步保存、待生效预算提示和折叠状态保留。原有 41 项规划、41 项子网、20 项事件、并发 JSON 写入及 14 项页面断言也通过。

实机确认当前 RSS、进程历史峰值、保护观测峰值和回收记录正确展示；在真实 LuCI 页面将 RSS 阈值由 96 改为 112 MiB，关闭保护并恢复 96 MiB，再重新启用，最后恢复原有全部保护设置。回收次数与冷却时间保留。只读会话能读取内存状态，不能提交内存设置；匿名写入被拒绝。桌面页面及概览入口已验收，未宣称本版重新进行手机视口或其他硬件测试。

两次操作期间共 120 次 Tailnet Ping，零丢包。LAN 到 Tailnet SSH、办公室 IPv4 HTTP、IPv4 代理和客户端 IPv6 直连/代理 HTTPS 均通过。网络、无线、DHCP、防火墙、网关策略、Tailscale 配置及偏好、DNSRouter/Mihomo 配置哈希保持一致；Tailscale、网络相关守护进程、DNSRouter、Mihomo 及原有网关工作进程身份保持不变。IPv6 既有路由未删除，仅有对应活跃 NDP 邻居的两个 LAN `/128` 主机路由自然增加。没有重启网络、Tailscale 或启用其待生效 Go 预算。

`0.2.2-r1` 将子网、DNS 和空闲状态采集的兜底周期默认改为 300 秒，并更新界面的有效期判断；事件与上联探测机制沿用前版。下表中完整 60 秒周期、事件恢复及重连的实机记录来自 `0.2.1-r1`，本版不将它们表述为重新测量的结果。本版实机确认三个后台任务的实际等待均为 `sleep 300`，DNS 持久配置为 300，事件唤醒正常；没有等待完整五分钟周期。网络、防火墙和 DHCP 配置未变化，Tailscale、dnsmasq 与上联进程 PID 保持一致。

`0.2.1-r1` 在 `0.2.0-r2` 基础上将子网和 DNS 同步改为事件触发，并降低空闲时的采集频率；在同一台设备完成升级与验收。此前版本已在一台使用 fw4、apk-tools 3 和 Tailscale 1.102.3 的 OpenWrt SNAPSHOT 设备上完成安装、接管、升级和客户端验证。这里仅发布方法和结果摘要；实机快照、后台截图及网络标识不随仓库分发。

## 复现

本地检查需要 Python 3、Node.js 18 或更新版本和 POSIX shell：

```sh
node tests/ui.cjs
python3 tests/uplink.py
python3 scripts/package.py
python3 scripts/source-package.py
```

ucode/DNS 测试需要可 SSH 访问的 OpenWrt 测试设备，具备项目依赖和 dnsmasq。`openwrt` 是文档约定的 SSH 别名，应指向自己的测试设备。以下命令将夹具放在 `/tmp/tsg-dev`，策略操作由测试替身处理：

```sh
python3 scripts/check.py openwrt
python3 tests/run.py openwrt
python3 tests/firewall.py openwrt
python3 tests/worker.py openwrt
python3 tests/dns.py
```

RPC 权限测试需要设备上已安装本插件，并有允许创建临时 ubus 会话的 SSH 权限。传入自己的管理 URL，例如 `python3 tests/acl.py http://router.example --host openwrt`。它只在内存中创建 30 秒会话，不创建账户、不保存口令，最终销毁会话。

## 尚未验证

本版未修改真实 Tailnet 的远端 DNS/路由发布配置；变化通知的筛选由合成夹具验证，订阅建立与重连使用实机验证。未执行实际拔线、整机重启、第二台物理设备或稳定版 SDK/IPK 构建。模拟故障测试证明控制逻辑，不等同于物理故障验收。LAN → Tailnet IPv6、其他 DNS 服务和使用远端 Exit Node 不在首版范围。
